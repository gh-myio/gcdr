Nome do dispositivo.

Formato legível PREFIX YYMMDD-NNNN que espelha o código numérico e é reversível: nome ⇄ B1.B2.B3.B4. Ex.: 3F 270102-0025 = um 3F feito em 02/01/2027, 25ª unidade do dia.

01 · Gerar

Campos → nome

3F 270102-0025
código: 17.2.25.15
02 · Converter

unit = seq3*254 + seq            // 1..2032  (seq3 0..7, seq 1..254)
name = `${PREFIX} ${yy}${mm}${dd}-${pad4(unit)}`   // SPACE após o prefixo
code = `${(year-2026)<<4 | month}.${seq3<<5 | day}.${seq}.${B4}`

* bytes de TEMP/TANK a ratificar no registro oficial.
