Código de produto com data.

4 bytes B1.B2.B3.B4: o código agora carrega a data de fabricação (ano/mês/dia), um sequencial diário e o tipo. Válido de 2026 a 2041.

03 · Layout de bits

Estrutura dos 4 bytes

Byte 1 YYYY MMMM YYYY = ano-2026 (0..15) MMMM = mês (1..12) Byte 2 SSS DDDDD SSS = seq3 (0..7) DDDDD = dia (1..31) Byte 3 NNNN NNNN sequencial diário (1..254) Byte 4 TTTT TTTT tipo (12=switch · 14=remote · 15=3f · 18=box)
const EPOCH_YEAR = 2026;
// encode
b1 = ((year - EPOCH_YEAR) << 4) | month;
b2 = (seq3 << 5) | day;
b3 = seq; b4 = type;
// decode
year  = EPOCH_YEAR + (b1 >> 4);   month = b1 & 0x0F;
seq3  = b2 >> 5;                   day   = b2 & 0x1F;
seq   = b3;                        type  = b4;
